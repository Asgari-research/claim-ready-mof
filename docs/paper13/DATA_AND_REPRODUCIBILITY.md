# Data and reproducibility scope

Final manuscript figures are stored under `figures/`. Reproduction code for the
final artwork is under `reproduce/figures/paper13/`.

Raw third-party MOF databases are not redistributed by this figure layer. Derived
figure-source tables should be committed only after their redistribution status
has been reviewed. Machine-specific absolute paths are not required for plotting
and should not be published.

The figure-rendering environment is a current reconstruction environment for the
publication graphics; it is not represented as the exact environment used for
the historical scientific analysis.
