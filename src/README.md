# Historical scientific-analysis source

This directory preserves the scientific-analysis scripts supplied for the Paper 13 study.

## Files

- `chemistry_ready_mof_analysis_pipeline_v2_2_claim_ready_sciml_visual_final.py` — historical resume-aware analysis pipeline.
- `make_publication_assets_v2_3.py` — historical publication-asset generator retained for provenance.

The canonical renderer for the **final** publication artwork is not the historical asset generator above. Final Main Figures 1–5 and SI Figures S0–S9 are regenerated by:

```text
reproduce/figures/paper13/
```

Only module docstrings were cleaned for public portability/provenance (stale local-path examples and stale release-role wording were removed). The supplied Stage-3 package includes a private static AST comparison showing that, after docstrings are removed from both versions, the executable ASTs are identical. This is a strong static check for this limited edit; it is not a full runtime-reproduction certificate.

The historical pipeline still contains legacy reporting/figure-generation logic, including references to an earlier six-main-figure architecture. Those executable strings and code paths are intentionally preserved rather than silently rewritten to match the final manuscript artwork.

The historical dependency list was unpinned and did not constitute an exact environment lockfile. The repository should therefore avoid claiming exact end-to-end reproducibility of the historical upstream run unless the missing environment/input dependencies are reconstructed and validated separately.
